## Principles

- Each phase should be independently valuable — deliver something usable
- Phases are sequential by default; parallel execution is opt-in via config.json
- Success criteria must be observable and verifiable, not aspirational
- 2-5 success criteria per phase — enough to verify, not so many they're noise
